# 🌦️ WeatherMitra

**WeatherMitra** is a simple yet elegant weather app built using modern Android development tools. It allows users to check the current weather of any location by integrating with the [WeatherAPI](https://www.weatherapi.com/). The app demonstrates clean architecture and modular design, making it a great starting point for scalable Android projects.

---

## 📱 Features

- 🔍 Search and update location
- ☀️ Real-time weather data (temperature, condition)
- 🖼️ Dynamic UI using Jetpack Compose
- 💡 Clean and minimal UX

---

## 🧰 Tech Stack

| Tool/Library     | Purpose                              |

| **Retrofit**     | API calls and networking             |
